# Classification Contract

Allowed finding classes:

- `CONFIRMED_ISSUE`
- `POTENTIAL_RISK`
- `SPEC_AMBIGUITY`
- `NO_ISSUE`

Use `CONFIRMED_ISSUE` only for a demonstrated mismatch against an
applicable authoritative expectation.

Use `POTENTIAL_RISK` for a plausible engineering concern that is not
established as a local requirement violation.

Use `SPEC_AMBIGUITY` when expected behavior cannot be determined safely.

Use `NO_ISSUE` when evidence supports alignment or harmlessness within the
evaluated scope.

Focused skills do not decide the final advisory.
