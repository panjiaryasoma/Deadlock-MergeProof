# Read-Only Enforcement

MergeProof verification mode is read-only.

Do not:
- create files;
- edit files;
- rename files;
- delete files;
- overwrite files;
- create plan artifacts;
- create report artifacts;
- modify source or tests;
- run mutation-oriented commands.

Return verification output in the conversation only.

Persisting a report requires a separate explicitly-authorized write step
outside this verification mode.
