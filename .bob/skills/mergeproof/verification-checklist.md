# Verification Checklist

- [ ] Change scope is explicit or limitation is disclosed.
- [ ] Relevant sources are inventoried.
- [ ] Explicit supersession is checked.
- [ ] ACTIVE was not automatically treated as AUTHORITATIVE.
- [ ] Source conflicts were not silently resolved.
- [ ] Implementation is separated from expected behavior.
- [ ] Tests are treated as evidence, not automatic authority.
- [ ] External best practice was not converted into a project requirement.
- [ ] Confirmed issues contain source evidence.
- [ ] Confirmed issues contain repository/test evidence.
- [ ] Severity was not invented without a rubric.
- [ ] Unspecified product decisions remain human decisions.
- [ ] Final advisory is PASS, REVIEW_REQUIRED, or ABSTAIN.
- [ ] No repository file was modified.
