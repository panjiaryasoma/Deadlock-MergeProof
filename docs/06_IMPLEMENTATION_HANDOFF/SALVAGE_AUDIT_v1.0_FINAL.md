# Salvage Audit

## Reused ideas
- acceptance fixtures as executable product contracts;
- schema-first output;
- deterministic gate after probabilistic reasoning;
- human authority boundary;
- source/feature traceability.

## Explicitly not copied
- ML training/calibration pipeline from unrelated projects;
- CP-SAT/optimization architecture;
- domain-specific triage semantics from other products;
- unnecessary API/backend layers.

## Reason
The workflow pattern is reusable. The domain logic is not.
