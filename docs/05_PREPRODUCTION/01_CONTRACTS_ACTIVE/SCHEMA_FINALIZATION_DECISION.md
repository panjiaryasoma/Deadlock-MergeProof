# Schema Finalization Decision

Status: **FROZEN FOR MVP**

Frozen:
- finding classes;
- advisories;
- evidence grades;
- source states;
- minimum evidence rules.

Allowed without schema change:
- wording improvements;
- optional metadata;
- additional evaluation cases using existing enums.

Requires schema change:
- new finding class;
- new advisory;
- weakening evidence invariants;
- granting automated merge authority.
