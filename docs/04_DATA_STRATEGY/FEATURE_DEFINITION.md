# Feature Definition

"Feature" here means a structured signal used by the verification workflow, not an ML input vector.

## Source features
- source type
- authority
- active/superseded/conflicting state
- scope
- version/effective date

## Requirement features
- atomic statement
- criticality
- ambiguity state
- explicit boundary terms
- linked artifact IDs

## Change features
- changed files
- changed symbols/lines
- diff type
- API/schema touch
- test touch

## Evidence features
- source anchors
- repo anchors
- test anchors
- evidence grade

## Output features
- finding class
- finding type
- severity
- advisory
- unresolved human question
